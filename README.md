## Cowsay in cpp

Simple Cowsay program in C++ 

# Compilation and run

Clone the repository
```bash
git clone https://github.com/Ars-byte/Cowsay_In_Cpp.git
```

Compile the program:

```bash
g++ main.cpp -o cowsay
```

Run the cowsay:

```bash
./cowsay hello world :D
```
